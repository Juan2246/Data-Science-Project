# Data Science Project

Proyecto final desarrollado como parte de la certificación **Data Science Foundations** (IBM, Coursera), aplicando el ciclo completo de análisis de datos.

## Contenido

- Limpieza y preparación de datos
- Análisis exploratorio de datos (EDA)
- Visualización de resultados
- Conclusiones basadas en los hallazgos del análisis

## Tecnologías

- Python
- Jupyter Notebook
- Pandas / Librerías de análisis y visualización de datos
